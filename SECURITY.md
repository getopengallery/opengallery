# Security policy

## Supported versions

OpenGallery is in early development. Security fixes go into the latest release only, so please keep your gallery up to date.

## Reporting a problem

Please do not report security problems in public issues.

Use [GitHub's private vulnerability reporting](https://github.com/getopengallery/opengallery/security/advisories/new) and include:

- the affected version;
- what an attacker could do;
- the steps to reproduce it;
- a suggested fix, if you have one.

Do not include real personal data or private photos. Test only on a gallery you own or may test.

Response times can vary. Reports are kept confidential until a fix is available.

## Scope

Examples of what we want to hear about: seeing or changing albums and photos without permission, bypassing a password or expiry date, privilege escalation, code execution, cross-site scripting and leaks of personal data or GPS locations.

Themes and plugins run code on the server. Report a problem in a third-party extension to its author.
