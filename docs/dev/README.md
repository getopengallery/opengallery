# Developer guide

This guide is for developers who customize or extend OpenGallery: theme and plugin authors, and contributors to the core code.

New to the code? Start with the [architecture overview](architecture/overview.md) and the [access model](architecture/access-model.md).

Everything an administrator does by clicking through the admin belongs in the [user guide](../user/README.md) instead.

## Contents

- [Architecture](architecture/README.md): how the code is put together, the access model, the data model and site settings.
- [Extending OpenGallery](extending/README.md): writing plugins and themes, blocks, and languages and translations.
- [Internals](internals/README.md): the media library and photo picker, uploads, the activity log and the admin UI conventions.
- [Working on the core](contributing/README.md): the frontend build, testing, commands and schedule, demo data and writing documentation.
