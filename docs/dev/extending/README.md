# Extending OpenGallery

How to change and extend OpenGallery without editing its core code. Plugins add behaviour, themes change everything visitors see, blocks are the building blocks themes work with, and every text can be translated or reworded.

- [Writing plugins](plugins.md): `plugin.json`, loading, hooks, the settings page, login options and adding extension points.
- [Dashboard widgets](dashboard-widgets.md): the widget registry, keys, `canView()`, scoping and caching, and adding a widget from a plugin.
- [Writing themes](themes.md): `theme.json`, tokens, palettes, view overrides, settings, child themes and wording.
- [Blocks](blocks.md): the blocks pages are built from, their props, how variants are chosen and adding a block.
- [Languages and translations](translations.md): who owns which text, choosing the language, and adding a language.
